Economy: 300 🪙 start, 100 🪙 per tree, 180 🪙 for a surreal species (`shared/lib/economy.ts`, per-species `price` / `seedPrice` in `shared/lib/treeSkins.ts`, charged by `seed_price()` in the database; changing a planted tree to a pricier species costs the difference); decks are created only through the `plant_deck()` or `clone_deck()` RPCs (cloning a shared tree costs `cloneCost(n)` = min(100 + statements, 150) 🪙); the Coin Shop's free top-up works only outside production. Gardens are isolated: `getDecks` returns only the session user's own decks; other gardeners' shared (`is_public`) trees are found by link: opening one (`/deck/[slug]`, signed in, not yours) records a visit (`TreeVisitTracker` → `recordTreeVisit` → `record_tree_visit()` RPC, table `tree_visits`), and the farm's left **Visited Gardens** drawer (`getVisitedGardens`, garden `VisitedGardensDrawer`) lists those trees by gardener; `getNeighborGarden` shows one gardener's shared island (read-only visitor mode, `/?visit=<id>`, which records no visits). There is no public directory of shared trees (Community Gardens and `getCommunityDecks` were removed). Visitor mode is **strict**: visitors read every root and statement (`getDeckReader`) but can't edit or practise; `getDrillSession` / `checkDrillAnswer` / `submitDrillResult` are owner-only (`FORBIDDEN_VISITOR_PRACTICE`, `shared/lib/visitor.ts` `canPractice`), so to practise they clone the tree (`cloneDeck`, progress not copied). The one exception is a **Mind Tournament** the owner hosts on a public tree (`decks.is_tournament_open`): signed-in visitors drill it with an isolated score (`deck_tournament_*` tables, never `user_progress` / streaks / coins), ranked on the 📜 Hall of Fame (graduates by fewest practice days) and 🌱 Active Learners boards (`shared/lib/visitor.ts` `tournamentAccess`). New trees are private by default. Mastery is 0–5 (`shared/lib/mastery.ts`, `MAX_MASTERY`); 5/5 items rest from normal drill rounds unless `?review=1`. The existing hosted project's base schema was built in the dashboard and already has files 2–3: never run the baseline there; apply new migrations in the SQL Editor.

- The repo path contains non-ASCII characters (`Tài liệu`). Quote paths in shell commands.
- When you add a feature, also create `src/features/<feature>/context.md` (owned tables, exports, dependencies) as the docs require.
